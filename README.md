# SQL Data Analysis Portfolio

## Project Overview

This project showcases my SQL skills through a series of 15 business-oriented data analysis problems using the AdventureWorks database.

The objective is to demonstrate how SQL can be used to extract, transform, analyse and interpret business data to support informed decision-making.

## Tools and Technologies

- MySQL
- AdventureWorks Database

## SQL Skills Demonstrated

This project demonstrates practical applications of:

1. SELECT statements
2. WHERE and ORDER BY clauses
3. INNER JOIN and LEFT JOIN
4. Aggregate functions (SUM, AVG, COUNT)
5. GROUP BY and HAVING
6. Subqueries
7. CASE statements
8. Data filtering and business analysis

## Project Structure

The portfolio contains 15 business-oriented SQL questions covering different aspects of business operations.

### Business Analysis Areas

- Human Resources Analysis
- Sales Performance Analysis
- Customer Analysis
- Inventory Management
- Product Performance Analysis
- Procurement Analysis
- Revenue Analysis

## Project Objectives

- Demonstrate practical SQL querying skills.
- Solve real-world business problems using relational databases.
- Extract meaningful insights from business datasets.
- Apply SQL techniques to support management decision-making.
